# Contributing

Thanks for your interest in contributing to CodexDS! To keep collaboration smooth:

- Fork the repository and create a branch for your change: `feature/xyz` or `fix/abc`.
- Open a pull request describing the change and linking any related issues.
- Keep changes small and focused. Include tests where appropriate.
- Follow existing code style and add comments for complex logic.

For major changes, open an issue first to discuss the design.
