# Hackathon Submission: CodexDS - Instant Decision Maker

Project name: CodexDS - Instant Decision Maker

One-line pitch: Make decisions instantly using a simple scoring flow and optional AI suggestions.

Problem statement:
Many people struggle with everyday decisions due to information overload or lack of structured comparison. This project helps users quickly weigh options and choose confidently.

Solution overview:
A lightweight web app that lets users input a decision and options, assign weights/criteria, and get ranked suggestions along with explanations. Optionally integrates AI to suggest options and explain reasoning.

Tech stack:
- Frontend: HTML, CSS, JavaScript
- Backend: Python (Flask/FastAPI) — optional
- Storage: LocalStorage or lightweight file-based persistence
