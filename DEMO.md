# Demo guidance

Create a short demo to include in your hackathon submission. Recommended:
- 30–90 second screen recording or GIF
- Show: launching app, creating a decision, adding options/criteria, viewing ranked result

Tools:
- OBS Studio (free)
- QuickTime (macOS)
- recordmydesktop (Linux)

Place the demo file in `assets/videos/` and add a short caption and link in the README.
