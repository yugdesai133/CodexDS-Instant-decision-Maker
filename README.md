# CodexDS - Instant Decision Maker

This repository contains the code for "Instant Decision Maker", a hackathon project that helps users make quick decisions using a simple decision flow and optional AI assistance.

## What this repo includes
- Web frontend (HTML/JS)
- Python backend (if used)
- Documentation and submission artifacts for hackathon

## Features
- Input a decision, get suggested options
- Weighted scoring and explanation for each option
- Save decisions locally

## Tech stack
- Python
- HTML/CSS/JavaScript

## Quick start
1. Clone the repo
   ```bash
   git clone https://github.com/yugdesai133/CodexDS-Instant-decision-Maker.git
   cd CodexDS-Instant-decision-Maker
   ```
2. If the project uses Python backend, create a virtual env and install requirements:
   ```bash
   python -m venv venv
   source venv/bin/activate  # or venv\Scripts\activate on Windows
   pip install -r requirements.txt
   ```
3. Run the app (example):
   ```bash
   python app.py
   ```
   Or open the frontend HTML files in the browser if this is a static web app.
